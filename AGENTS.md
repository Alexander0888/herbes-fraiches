# Rayon 74

- Приложение для сотрудников отдела овощей и фруктов. Интерфейс — на французском, объяснения пользователю — на русском простыми словами.
- Стек: React, Vite, JavaScript, обычный CSS. Продолжаем существующий репозиторий.
- Общие страницы и навигация находятся в `src/app/` и `src/pages/`, инструменты — в `src/features/`, вход и Supabase — в `src/services/`.
- При планировании новых разделов сверяйся с `ROADMAP.md`. Не создавай функциональность за карточками «En développement» без задачи пользователя.
- Сохраняй существующие шаблоны, опубликованный снимок и правила доступа. Просмотр схемы публичный; редактирование защищено Supabase Auth и RLS.
- Доска трав всегда 6×8. Сохраняй её металлическое оформление, размеры подписей, цвета и порядок трав, если задача не требует их изменить.
- Учитывай телефон и планшет: до 700 px — стилизованный выбор трав; от 701 до 1000 px — кнопки под доской; шире — справа.
- Черновик не должен теряться без предупреждения при переходах, смене режима, шаблона и выходе. Сохранение шаблона и применение схемы — отдельные операции.
- Не помещай пароли, приватные ключи, файлы `.env.*` и локальные учётные записи в Git, логи или сборку. Публикуемый ключ Supabase рассчитан на браузер.
- Используй отдельную ветку для заметных изменений: обновление `main` запускает публикацию сайта.
- Базовые проверки: `npm test`, `npm run build`. Для навигации и интерфейса — `npm run test:ui`; для общей базы — `npm run test:shared` и `npm run test:ui:shared` на локальном Supabase.
- Не запускай изменяющие данные тесты против рабочей облачной базы. Различай эмуляцию размеров экрана и проверку на физических устройствах.
- При изменении структуры или поведения обновляй `README.md` и соответствующие пункты `ROADMAP.md`.
